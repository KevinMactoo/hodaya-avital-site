# hodayaavital.com

Booking site for Afro & Hip Hop dance classes with Hodaya Avital.

A static site (no build step): `index.html` plus two photos. Booking requests are sent to Hodaya on WhatsApp.

## Deploy

Hosted on Vercel. Every push to `main` deploys automatically.
In Vercel: Framework Preset **Other**, no build command, output directory = repo root.
